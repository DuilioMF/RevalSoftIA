# RevalSoftIA — Gestión Empresarial Inteligente

![RevalSoftIA Banner](hero-illustration.png)

## 🧠 Memoria del Proyecto
Este repositorio contiene el sistema web de **RevalSoftIA**, la evolución del ERP tradicional de RevalSoft potenciado con Inteligencia Artificial. El objetivo es transformar la gestión empresarial mediante herramientas predictivas y asistentes virtuales.

### 🎨 Sistema de Diseño (Branding)
Para mantener la consistencia en el futuro, este proyecto sigue estas reglas:
- **Estética:** Premium, Moderna, Dark Mode.
- **Paleta de Colores:**
  - Principal: `#ff6c4e` (Naranja-Rojo)
  - Acento: `#e44160`
  - Fondo: `#1a1a1f`
- **Tipografía:** Montserrat (Google Fonts) para todos los elementos.
- **Efectos:** Glassmorphism, gradientes vibrantes y micro-animaciones.

### 🚀 Funcionalidades Clave
1. **Asistente de WhatsApp:** Integración con un bot de IA para consultar ventas, stock y estadísticas en tiempo real (+54 9 3415 31-0874).
2. **Predicción de Demanda:** Algoritmos de Machine Learning para optimizar stock.
3. **Facturación Electrónica:** Conexión directa con AFIP.
4. **Modo Dual:** Soporte nativo para Temas Claro y Oscuro.

### 🛠️ Tecnologías
- **Core:** HTML5, CSS3 (Vanilla), JavaScript (ES6+).
- **Formularios:** Integración con Formspree para gestión de leads.
- **Iconografía:** Font Awesome 6.

### 📁 Estructura de Archivos
- `index.html`: Estructura principal y secciones.
- `styles.css`: Sistema de diseño y animaciones.
- `script.js`: Lógica de interacción, partículas y animaciones de scroll.
- `CNAME`: Configuración para el dominio `www.revalsoftia.com.ar`.
